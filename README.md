# Android Mirroring

iPhone 미러링처럼 안드로이드 휴대폰 화면을 Mac 창에 띄워 마우스·키보드로 조작하는 앱입니다.
[scrcpy](https://github.com/Genymobile/scrcpy) 위에 얹은 얇은 래퍼입니다.

- 미러링 중 휴대폰 화면은 꺼지고 Mac에서 조작
- 연결 중 휴대폰 잠김 방지
- 소리도 Mac으로 출력 (Android 11+)

## 설치

```bash
brew install scrcpy android-platform-tools
```

[Releases](../../releases)에서 `Android-Mirroring.zip`을 받아 압축을 풀고 `/Applications`로 옮깁니다.
서명되지 않은 앱이므로 처음 실행 시 우클릭 → 열기.

## 휴대폰 연결

- **USB**: 개발자 옵션 → USB 디버깅 켜고 케이블 연결
- **무선**: 개발자 옵션 → 무선 디버깅 → `adb pair <IP:포트>` 후 `adb connect <IP:포트>`

`adb devices`에 기기가 보이면 앱을 실행하세요.

## 연결 / 연결 해제

- 휴대폰이 하나만 연결되어 있으면 앱을 열자마자 미러링이 시작됩니다. 이미 실행 중일 때 다시 열면 미러링 창을 앞으로 가져오거나 다시 연결합니다.
- 미러링 창 바로 아래에 **연결 해제** 막대가 붙어 있습니다. 해제하면 연결 창이 열립니다.
- **연결 창**에서는 연결된 휴대폰(유선/무선 표시)을 골라 미러링을 시작하고, 연결 방법을 고를 수 있습니다.
  - **유선 (USB)**: USB 디버깅을 켜고 케이블을 꽂으면 목록에 자동으로 나타납니다.
  - **무선 (같은 Wi-Fi)**: 한 번 페어링한 휴대폰은 무선 디버깅을 켜면 자동으로 나타납니다. IP 주소:포트로 직접 연결하거나, 처음이면 페어링 코드로 페어링합니다.
- 휴대폰이 없거나 여러 대면 앱을 열 때 연결 창이 뜹니다.
- 메뉴 막대 아이콘에서도 휴대폰별로 연결 / 연결 해제하고, **연결 방법…** 으로 연결 창을 열 수 있습니다.
- Dock에는 Android Mirroring 아이콘 하나만 보입니다 (미러링 중에는 미러링 창이 그 아이콘을 씁니다).
- 여러 대를 동시에 미러링할 수 있습니다. 미러링 창 제목이 기기 모델명입니다.

## 키보드와 단축키

Mac 키보드가 휴대폰에 **실제 블루투스 키보드처럼** 연결됩니다 (`--keyboard=uhid`).
한글 입력, Ctrl/Option 조합, 방향키 모두 휴대폰으로 그대로 전달됩니다.
미러링 창에서 **한/영 키(Caps Lock)** 를 누르면 휴대폰 키보드의 한/영이 전환됩니다.
Ctrl+Space처럼 Mac 입력 소스를 바꾸는 단축키도 휴대폰에 같이 적용됩니다.
(macOS는 미러링 창 안에서 Caps Lock 한/영 전환을 하지 않기 때문에, 앱이 키를 가로채 휴대폰에 언어 전환 키를 보냅니다. 소스: `AndroidMirroring.swift`)

> 처음 실행하면 **손쉬운 사용** 권한을 요청합니다. 시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용에서 Android Mirroring을 켜세요.
> 앱을 새 버전으로 바꾸면 권한을 다시 켜야 할 수 있습니다.

`Cmd`는 미러링 단축키 전용입니다:

| 단축키 | 동작 |
|---|---|
| `Cmd+H` | 홈 |
| `Cmd+B` / 우클릭 | 뒤로 |
| `Cmd+S` | 최근 앱 |
| `Cmd+M` | 메뉴 |
| `Cmd+C` / `Cmd+X` | 휴대폰에서 복사/잘라내기 (Mac 클립보드와 동기화) |
| `Cmd+V` | Mac 클립보드 붙여넣기 |
| `Cmd+↑` / `Cmd+↓` | 볼륨 |
| `Cmd+P` | 전원 |
| `Cmd+O` / `Cmd+Shift+O` | 휴대폰 화면 끄기/켜기 |
| `Cmd+R` | 화면 회전 |
| `Cmd+F` | 전체 화면 |
| `Cmd+N` / `Cmd+Shift+N` | 알림창 열기/닫기 |
| `Cmd+K` | 휴대폰의 물리 키보드 설정 열기 (자판 배열 설정) |

전체 목록: [scrcpy shortcuts](https://github.com/Genymobile/scrcpy/blob/master/doc/shortcuts.md)
